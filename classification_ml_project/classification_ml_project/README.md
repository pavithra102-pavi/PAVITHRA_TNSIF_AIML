# Classification Model Training Project

Train and compare seven supervised classification algorithms using a sample dataset included with scikit-learn.

> **Educational example only:** this dataset relates to breast tumors. The models are not medical devices and must not be used for diagnosis or treatment decisions.

## Algorithms
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Gaussian Naive Bayes
- Gradient Boosting

## Requirements
- Python 3.10 or newer recommended
- pip

## Setup

```bash
python -m venv .venv
```

Activate it:

**Windows**
```bash
.venv\Scripts\activate
```

**macOS/Linux**
```bash
source .venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Train all models

```bash
python train_models.py
```

The script creates:
- `sample_dataset.csv` — exported example dataset
- `model_comparison.csv` — test metrics for all algorithms
- `metadata.json` — selected model and feature names
- `models/*.joblib` — trained model files

The dataset is split into training and test portions. The test portion is held out from fitting. Models are compared using accuracy, macro precision, macro recall, and macro F1. The selected model is the one with the highest macro F1 on this single split; results can vary with data and split.

## Make predictions

```bash
python predict.py
```

Choose option 2 to run a demonstration using the first feature row, or option 1 to provide a CSV containing the same feature columns as the training dataset. Do not include the `target` column in new input data.

## Important notes
- The sample CSV and model files are generated when you run the training script.
- Keep training and prediction feature columns consistent.
- For real projects, validate with domain-appropriate data, cross-validation, and relevant metrics. Accuracy alone is not enough for imbalanced or high-stakes tasks.
